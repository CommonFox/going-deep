# ESPN draft sheet — 2026

**League:** ESPN, 10-team, **1QB** (no superflex), full PPR, 20 roster spots (QB / RB×2 / WR×2 /
TE / FLEX / K / P / DST / 7 bench / 2 IR). This league also starts a **punter** — the one position
no external projection source in this warehouse prices; `punter_projections` is the only model that
does.

**Seat: not yet known.** ESPN's `draftSettings.orderType` is `DRAFT_START`, which randomizes the
pick order when the draft room opens — the `pickOrder` already sitting in the league record is
provisional and `src.draft.live_espn` refuses to resolve a seat from it before then (confirmed live
against the real league on 2026-09-08: it refuses with exactly that message). **THE SHEET's
pick-by-pick table and the opening plan (Convo A) can't be written until the order is drawn** — see
the TODO at the bottom. Everything below this point doesn't need a seat.

All numbers are from the warehouse build (days-old, not recomputed live): `draft_board`
(points over replacement = **POR**), `archetype_outcomes` (surplus by career-stage archetype). Both
filtered to `league_key = 'espn'` — this league's own scoring and replacement level, not
Sleeper's superflex numbers.

## Convo B — archetypes & tiebreakers, this league's own numbers

### The two signals this league's data actually clears

`archetype_outcomes`, 8 seasons, **espn** (crossed against `draft_value`'s ADP-relative surplus, not
raw draft-day surplus — see `player_archetypes.py`'s docstring for why that adjustment matters).
Same two cells the Sleeper sheet found are reliable here too, with this league's own numbers:

| Archetype | Edge vs ADP | |
|---|---|---|
| **RB / Proven Prime** (young/prime **and** a prior elite finish) | **+11.9 pts** (t = 1.72) | target |
| **WR / Unproven Veteran** (journeyman, never elite, 27+/7yr+) | **−3.8 pts** (t = −4.0) | fade |

Everything else the table reports — QB Proven Prime, RB Proven Veteran, TE Proven Prime, WR Proven
Prime, and the rest — is gated off (`is_reliable = False`): the surplus mean is close enough to zero,
or the standard error wide enough, that it isn't distinguishable from noise. Notably QB shows
**nothing reliable at all** in this league, unlike a superflex league where QB is where the real
signal concentrates — 1QB doesn't reward or punish a QB archetype the way owning two QB slots does.

- **Proven Prime RBs in range:** Gibbs, Bijan, Jonathan Taylor, Achane, CMC, James Cook, Chase
  Brown, Saquon, Jeanty — the same names the Sleeper sheet flags, because the archetype
  classification (`player_archetypes`) is a fact about the *player*, not the league.
- **Unproven Veteran WRs to fade:** the same "aged, never-elite journeyman" shape — check this
  league's specific waiver/bench options against `player_archetypes` closer to the draft, since the
  exact names available this late will depend on who's gone by each pick.

### Color: QBs still don't bust, but this league doesn't pay extra for two of them

Every QB archetype's `injured_rate`/`busted_rate` pattern (get hurt or deliver, essentially never
"bust" the way a bench RB does) holds regardless of league — that's a fact about the position, not
the scoring format. What's different here is the *why-it-matters*: in the superflex league two
starting QB slots make position 2 of that pair nearly as valuable as position 1, which is what
forces the QB run in rounds 2-3. In a 1QB league there's only one slot to fill, so the QB
POR curve (Josh Allen 59, next tier Lamar 38.5, Hurts 30.7 — nothing like the superflex board's
Josh Allen at 140) never creates that same urgency. `draft_strategy_summary`'s own superflex
counterfactual (see `README.md`'s `draft_strategy.py` entry) says this directly: point the model at
this league's real (non-superflex) settings and it stops recommending an early quarterback.

## Convo C — the endgame, adjusted for a 20-round, punter-starting league

### K / P / DST

`draft/hold.py`'s rule: reserve one round per late slot the league starts, counted back from the
end. This league starts **three** such slots (K, P, DST — Sleeper's has no punter, hence only
K + DST there), so reserve = 3 and `from_round = rounds - reserve + 1 = 20 - 3 + 1 = 18`. The live
tool holds all three off the default board until **round 18**, whichever three picks that turns out
to be once the seat is known. Typing `k`, `p` or `dst` overrides it at any point.

That round-18 cutoff isn't an arbitrary reserve either — it lines up with where this board's own
value genuinely runs out (see below), which is the same alignment the Sleeper sheet noted for its
own K/DST cutoff.

### The value window, read off the board's own POR curve

Grouping `draft_board` by ADP-implied round (10-team snake, so round *r* ≈ ADP 10(r−1)+1 to 10r) and
taking the best POR available in each round:

| Round band | Best POR still available |
|---|---|
| 1–11 | 27–163 (real, startable value every round) |
| 12–14 | 8–18 (thin, but still positive) |
| 15–17 | roughly flat, -7 to +18 (noisy — small samples, a few injured-discount RBs) |
| 18–22 (K/P/DST unlock here) | flat at roughly 0–5 |

**The value window is rounds 1–14, not 15+.** By round 15 the board stops offering anything
reliably above replacement, which is a few rounds later than the Sleeper sheet's read of its own
board (rounds 6–9) — expected, since a 10-team league has a shallower player pool draining slower
per round than a 14-team one, but the shape (real value early, flat late, K/P/DST landing right in
the flat part) is the same finding twice.

### "Super-low ADP players we can differentiate"

Same caveat as the Sleeper sheet: `draft_value`/`player_archetypes` read the wrong ADP for whichever
league doesn't match their join (see the bug note at the bottom of `sleeper-2026.md` — same root
cause, `adp_consensus`'s `(player, format)` join). Re-check `draft_board`'s own blended view (which
joins correctly) closer to the draft for this league's specific market-vs-model gaps, rather than
trusting `draft_value`/`player_archetypes` numbers directly.
